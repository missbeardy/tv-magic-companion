## Things worth knowing that cost me time yesterday

- **The permission classifier blocks prod writes** — DDL, bulk deletes, and minting auth links. Expect
  to run those yourself, or add a Bash permission rule first.
- `profiles.email` exists on **dev** (NOT NULL) but **not on prod**. Nothing reads it.
- `auth.users.last_sign_in_at` is **not** a proxy for "last opened the app" — it only moves on an
  actual sign-in and this team stays logged in. Every profile reads June/July while rows were being
  written that same day.
- `Demo Manager` and `Demo Employee` in the prod TV Magic org are **sanctioned** test accounts. Don't
